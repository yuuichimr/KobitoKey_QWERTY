# KobitoKey_QWERTY

## このブランチの変更（2026-10-02）

- 目的: まずトラックボールの役割を固定で左右逆にする。左=カーソル、右=縦スクロール。
- 左ボールで既存の自動マウスレイヤー3に入る。5秒の時間設定・U/I/Oのクリック配置は維持。
- 感度は役割に合わせ左600 CPI、右200 CPI。左右固有の回転角・軸補正は維持。
- デフォルトのキー配列は変更しない。mona2に近づける配列と、ボタンでの左右切り替えは後続の検討として保留。
- 次の確認: 左右ファームのビルド後、実機で左の上下左右移動・右の縦スクロール・左操作後のU/I/Oクリック・通常文字入力への復帰を確認する。実機確認前に完了とはしない。
- 元設定: `1c81c9ba25f03d0a35d67c565c3dffc0f47327f0`。ローカルの `../01_デフォルト_20261002/` に変更前の設定一式を保存済み。
